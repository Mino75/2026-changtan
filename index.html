Changtan Web Chat — Production Demonstrator

This page demonstrates the Changtan widget exactly as it runs on a customer website: loaded as an external script, configured via window.CTChatConfig, and rendered as a floating UI. Use this page to validate visual fidelity, z-index behavior, scroll robustness, and responsive performance.

To run a full end-to-end demo, set wsEndpoints to a real wss:// endpoint. If this page is served over HTTPS, do not use ws:// endpoints (browsers will block mixed content).
